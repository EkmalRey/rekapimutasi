Rekap mutasi bank, jadi tabel.

Tarik statement PDF atau CSV (bisa banyak file sekaligus) — BCA, Jago, Mandiri, BNI, BSI, Jenius, BRI. Transaksi dirapikan jadi baris bersih: tanggal, tipe, nominal, saldo. Lalu unduh .xlsx atau .csv.
